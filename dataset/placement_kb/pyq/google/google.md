# Google SWE — Previous Year Questions (PYQ)

Source: Sample compiled set for campus SWE / intern drives.

## Coding Rounds
- Given a binary tree, return its level-order traversal.
- Find the longest substring without repeating characters.
- Word Break: determine if a string can be segmented using a dictionary of words.
- Dijkstra's shortest path on a weighted graph.

## System Design (for experienced roles)
- Design a URL shortener; discuss hashing, storage, and scaling.
- Design an autocomplete/typeahead service.

## Googliness & Leadership
- Behavioural questions on collaboration, dealing with ambiguity, and impact.

## Notes
Google interviews emphasise clean, optimal code with clear complexity analysis and strong
communication. Expect follow-ups that push you to improve time/space complexity.

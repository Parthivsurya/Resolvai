# Amazon SDE — Previous Year Questions (PYQ)

Source: Sample compiled set for campus and off-campus SDE-1 drives.

## Online Assessment (Coding)
- Given an array of integers, find two numbers that add up to a target (Two Sum).
- Find the number of islands in a 2D grid of land and water.
- Return the K largest elements in an array using a heap.
- Merge K sorted linked lists into one sorted list.

## Work Simulation & Leadership Principles
- Behavioural questions mapped to Amazon's Leadership Principles (Customer Obsession,
  Ownership, Dive Deep, Bias for Action).
- Situational judgement scenarios about handling ambiguous tickets and tight deadlines.

## Technical Interview
- Data structures: trees, graphs, tries, heaps; complexity analysis.
- Low-level design: design a parking lot, design an LRU cache.

## Notes
Amazon SDE interviews weigh DSA problem-solving heavily and always include Leadership
Principle behavioural rounds. Prepare STAR-format stories for each principle.

# Infosys SP/DSE — Previous Year Questions (PYQ)

Source: Sample compiled set for on-campus drives.

## Reasoning Round
- Seating arrangement puzzles (circular and linear).
- Blood relation and syllogism questions.
- Data sufficiency questions.

## Coding Round
- Find the second largest element in an array without sorting.
- Check if two strings are anagrams of each other.
- Reverse a linked list iteratively.

## Pseudocode Round
- Questions test understanding of loops, arrays, and function output tracing.

## Notes
Infosys has a Specialist Programmer (SP) track with a harder coding test and a Digital
Specialist Engineer (DSE) track. The System Engineer (SE) role uses the standard InfyTQ
based assessment.

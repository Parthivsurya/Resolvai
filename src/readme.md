# PYQs of Top Tier Companies

## Dataset Description

This dataset contains commonly asked questions relevant to interview preparation, along with selected previous-year questions (PYQs) and coding problems associated with leading technology companies. It is intended to support students preparing for campus placements, technical interviews, and company-specific recruitment assessments.

## Dataset Contents

The dataset includes interview-preparation questions and available company-specific placement materials. The questions can be used for interview practice, educational applications, question-answering systems, and information retrieval research.

## Intended Use

The dataset can be used to develop and evaluate interview-preparation chatbots, semantic search systems, and Retrieval-Augmented Generation (RAG) applications.

## Usage Instructions

Download the dataset and inspect the included files to understand their formats and contents. The questions can be used directly for practice or processed for use in search and question-answering applications. Verify company-specific recruitment information independently, as interview patterns and eligibility criteria may change over time.

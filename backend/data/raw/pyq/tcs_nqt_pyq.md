# TCS NQT — Previous Year Questions (PYQ)

Source: Campus placement drive, sample compiled set.

## Aptitude Round
- A train 240 m long crosses a pole in 12 seconds. Find its speed in km/h. (Answer: 72 km/h)
- If the ratio of ages of A and B is 5:7 and their sum is 48, find B's age. (Answer: 28)
- Find the compound interest on Rs. 10000 at 10% per annum for 2 years. (Answer: Rs. 2100)

## Programming / Coding Round
- Write a program to check whether a given number is an Armstrong number.
- Print the Fibonacci series up to N terms using recursion.
- Given a string, count the number of vowels and consonants.

## Verbal Ability
- Reading comprehension passages followed by inference questions.
- Sentence completion and error-spotting questions.

## Notes
TCS NQT typically has sections for Numerical Ability, Verbal Ability, Reasoning Ability,
and a Programming Logic + Coding section. The coding section usually has one or two questions
solvable in C, C++, Java, or Python.
